# CleanUp Map

*See it. Map it. Clean it. Together.*

A web app where communities report dirty places on a map, organize cleanup events, and share the before & after.
Built with Next.js, Supabase, Leaflet/OpenStreetMap and deployed on Vercel.

## Getting started

```bash
npm install
cp .env.example .env.local   # fill in your Supabase values
npm run dev
```

Open http://localhost:3000. See `CLAUDE.md` for scripts, structure and conventions.
